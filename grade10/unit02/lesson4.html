Useful language

Four ways to give a reason

Everyday

We should recycle because it saves resources.
We should recycle, since it saves resources.

More formal

As it saves resources, we should recycle.
We should recycle due to the fact that it saves resources.

Which one would you use in a class presentation? Any of them — but vary. Four sentences all starting with because sounds like a list, not an argument.

Task 3 · Group presentation

What should teenagers do to live green?

Two actions to do · two actions to avoid · one reason each.

“There are many practical actions we should and shouldn’t take to live green. We should recycle used items since this conserves natural resources. On the other hand, we shouldn’t leave appliances on when we are not using them because this wastes electricity and increases our carbon footprint.”

Post-speaking

Three mistakes to watch for

  • 1️⃣

    Action without reason

    “We should recycle.” — and then nothing. Always add the why.

  • 2️⃣

    Wrong verb after should

    “We should to recycle” → we should recycle.

  • 3️⃣

    Blends slipping

    plastic · green · protect — no vowel between the two letters.

Corrections go on the board with no names. Write the wrong sentence, let the class fix it, then move on. Naming who said it stops the next student from volunteering.
